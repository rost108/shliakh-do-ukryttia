# Шлях до укриття

Гра-тренування від **Hobbit House** для телефона: пройди кварталами від дому до укриття, збери дорогою тривожну валізку і вкладися в норматив.

**Грати:** https://rost108.github.io/shliakh-do-ukryttia/

## Встановити на телефон

- **Android (Chrome):** відкрий посилання → кнопка «Встановити застосунок» на стартовому екрані гри (або меню ⋮ → «Встановити застосунок»). Гра з’явиться серед застосунків з іконкою Hobbit House.
- **iPhone (Safari):** відкрий посилання → «Поділитися» → «На початковий екран».

Після першого запуску гра працює **без інтернету** — дані кешуються на телефоні.

## Як грати

- **Свайп** у потрібний бік або **дотик** збоку від себе — рух до найближчого повороту (коридор гравець проходить сам).
- **Хрестик-кнопки** вмикаються в нижньому рядку; утримання кнопки веде далі на кожному перехресті.
- На комп’ютері — стрілки або WASD, `R` — почати рівень заново, `C` — ракурс камери.
- **Три арки за рівень:** дійти до укриття, вкластися в норматив часу, зібрати всю тривожну валізку (документи, вода, ліхтарик, аптечка, павербанк).
- **Монетки й персонажі:** монетки лежать на вулицях; монетки рівня можна зібрати один раз, у лабіринті дня — нові щодня; бонус 5 монеток за перші три арки на рівні й 5 за першу блискавку (рівень, пройдений удвічі швидше за норматив). За монетки відкриваються персонажі: котик-таббі (10), бігунка (20), пекінес (35), службова вівчарка (50), інженер у касці (70), їжачок (100); людина є з початку.
- **Лабіринт дня:** один лабіринт на день для всіх (нова дата — опівночі за Києвом), окрема таблиця «Лабіринт дня».
- **Виклик другу:** після рівня кнопка «Викликати друга» надсилає посилання на той самий лабіринт із твоїм часом (на телефоні — разом із картинкою-результатом).
- **Звук** — синтезований у браузері, без сирен; вимикається кнопкою з динаміком.
- **Плюшки на вулицях** (підбираються на ходу): швидкий крок, план району, компас (шлях до укриття), секундомір (час стоїть), рація (уся валізка на мапі).
- Кожен третій рівень — **знеструмлення**: світло лише довкола тебе, ліхтарик розширює огляд. Орієнтир — жовтий промінь над укриттям, мапа в куті малює лише розвідані вулиці.

## Що всередині

| Файл | Що це |
|---|---|
| `index.html` | 3D-версія (Three.js з cdnjs, один файл) |
| `2d.html` | легка 2D-версія для слабких телефонів |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | встановлення на головний екран |
| `sw.js` | офлайн-кеш: гра, 3D-рушій, шрифти, моделі персонажів (аналітику не кешує) |
| `promo-1280x720.jpg` | картинка для прев’ю посилань (виклики в месенджерах) |
| `models/*.glb`, `three-gltf-loader.js` | моделі людини, бігунки, інженера й вівчарки та їхній завантажувач |

Укриття на фініші — «Фортеця 3,5» від Hobbit House у трьох секціях (8,28 × 5,23 м), геометрія оболонки з робочої CAD-моделі.
Факти після рівнів — лише підтверджені дані Hobbit House. Локацій реальних об’єктів у грі немає.

Моделі людини, бігунки, інженера й вівчарки та анімації бігу — [Microsoft Rocketbox Avatar Library](https://github.com/microsoft/Microsoft-Rocketbox) (ліцензія MIT, `models/LICENSE-Rocketbox.txt`); куртку перефарбовано в жовтий, рюкзак, креслення й нашийник додано в грі. Котик, пекінес і їжачок — процедурні моделі гри.
