# Шлях до укриття

Гра-тренування від **Hobbit House** для телефона: пройди кварталами від дому до укриття, збери дорогою тривожну валізку і вкладися в норматив.

**Грати:** https://rost108.github.io/shliakh-do-ukryttia/ — відкрий на телефоні, а в меню браузера обери «На початковий екран», щоб гра запускалась як застосунок на весь екран.

## Як грати

- **Свайп** у потрібний бік або **дотик** збоку від себе — рух до найближчого повороту (коридор гравець проходить сам).
- **Хрестик-кнопки** вмикаються в нижньому рядку; утримання кнопки веде далі на кожному перехресті.
- На комп’ютері — стрілки або WASD, `R` — почати рівень заново, `C` — ракурс камери.
- **Три арки за рівень:** дійти до укриття, вкластися в норматив часу, зібрати всю тривожну валізку (документи, вода, ліхтарик, аптечка, павербанк).
- **Персонажі:** людина є з початку; рудий котик-таббі (4 арки), пухнастий пекінес (9 арок) та інженер у касці з кресленням (15 арок) відкриваються арками за рівні — вибір у меню «Персонаж».
- Кожен третій рівень — **знеструмлення**: світло лише довкола тебе, ліхтарик розширює огляд. Орієнтир — жовтий промінь над укриттям, мапа в куті малює лише розвідані вулиці.

## Що всередині

| Файл | Що це |
|---|---|
| `index.html` | 3D-версія (Three.js з cdnjs, один файл) |
| `2d.html` | легка 2D-версія для слабких телефонів |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | встановлення на головний екран |

Укриття на фініші — «Фортеця 3,5» від Hobbit House у трьох секціях (8,28 × 5,23 м), геометрія оболонки з робочої CAD-моделі.
Факти після рівнів — лише підтверджені дані Hobbit House. Локацій реальних об’єктів у грі немає.
